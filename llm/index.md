title: LLM Engineering
---
Everything an engineer needs to build LLM systems that hold up in production, in the order you need it: how the models work, how to talk to them, how to give them your data, how to let them act, how to know they work, how to adapt them, how to serve them, and how to run them safely.

| Phase | Topic | What you should be able to do |
|---|---|---|
| 1 | Foundations | Explain tokens, attention, pretraining and sampling, and pick a model for a job |
| 2 | Prompting and context | Get reliable, structured output and spend the context window well |
| 3 | Retrieval | Build a RAG pipeline that finds the right passages and cites them |
| 4 | Agents | Design tool-using agents that stay bounded, recover from errors and remember |
| 5 | Evaluation | Prove a change helped, offline and in production |
| 6 | Fine-tuning | Decide when to fine-tune, prepare data, and run SFT, LoRA and preference tuning |
| 7 | Inference and serving | Size GPUs, serve open models fast and cheap, and explain why |
| 8 | Production | Run it: routing, caching, reliability, tracing, guardrails, privacy and LLMOps |

Every note ends with interview questions and primary sources.
