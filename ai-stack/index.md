A roadmap for Python AI engineer roles that ask for **FastAPI, Pandas, LangChain and LangGraph** on top of LLM and RAG experience. Each phase goes from first principles to production, with code that runs against current library versions (FastAPI 0.16x, pandas 3, LangChain 1.x, LangGraph 1.x) and practice tasks at the end of every note.

| Phase | Topic | You should be able to |
|---|---|---|
| 1 | FastAPI | Build a typed, tested, async API that streams LLM output and enforces auth |
| 2 | Pandas | Clean, join, reshape and validate finance data fast, and prepare it for LLMs |
| 3 | LangChain | Call any model, get structured output, compose runnables, build RAG and tools |
| 4 | LangGraph | Build stateful agents with tools, memory, human approval and multiple agents |
| 5 | Putting it together | Ship a finance RAG agent end to end and defend it in an interview |
